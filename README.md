# Kid Seat Match 🚗🧒

Прототип фичи для сервиса безопасных поездок с детьми: родитель один раз
указывает возраст, рост (и опционально вес) ребёнка — система определяет
нужную **группу автокресла** (автолюлька / кресло / бустер) и при заказе
показывает только машины с подходящим креслом.

Мобильное SPA в тёмной «safety»-стилистике. Без бэкенда: машины — мок-массив,
профили детей хранятся в localStorage.

## Запуск

```bash
npm install
npm run dev    # http://localhost:5173
npm test       # юнит-тесты логики подбора кресла
npm run build  # продакшен-сборка
```

## Структура

| Путь | Что это |
|---|---|
| `src/lib/seatGroup.js` | Ядро: чистая функция `getSeatGroup` (подбор группы по ECE R129/R44, приоритет рост → вес → возраст) и `carFitsChildren` (матчинг машины под нескольких детей) |
| `src/lib/seatGroup.test.js` | 35 тестов: все строки таблицы групп, граничные значения (87/105/125/150 см), конфликты рост/возраст, мультидети |
| `src/screens/` | 4 экрана: Home, профиль ребёнка (с живым расчётом), заказ поездки, подтверждение |
| `src/data/cars.js` | Мок-машины с разными наборами кресел |

## Логика подбора (кратко)

- Рост — главный критерий (стандарт i-Size); возраст — fallback, вес — уточняющий фильтр.
- Зоны пересечения групп → более безопасная (младшая) группа + подпись «также подойдёт …».
- Конфликт роста и возраста → приоритет роста + мягкое предупреждение.
- Возраст 12+ или рост 150+ см → кресло не требуется, фильтр машин отключается.
- Несколько детей → машина должна иметь **все** нужные кресла одновременно.
